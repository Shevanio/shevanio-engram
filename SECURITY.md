# Security policy

## Supported versions

The canonical npm package is unpublished. Only the current `main` branch is supported for security fixes.

| Target | Supported |
| ------ | --------- |
| Current `main` | Yes |
| Canonical npm package | No published release |
| Earlier commits or downstream copies | No |

## Report a vulnerability privately

Use [GitHub Private Vulnerability Reporting](https://github.com/Shevanio/shevanio-engram/security/advisories/new). Do not open a public issue or include vulnerability details in public discussions, pull requests, or logs.

After a private report is received, expect an acknowledgement confirming receipt and, when needed, a request for reproduction or impact details. Acknowledgement, investigation, and remediation timing depend on the report; this project does not promise fixed response or resolution times.
